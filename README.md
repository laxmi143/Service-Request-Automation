Service Request Automation
Overview

Service Request Automation is an end-to-end workflow solution built using Microsoft Forms, Power Automate, SharePoint Online, Outlook, and Microsoft Teams. The project streamlines the service request process by automating request submission, approval routing, status tracking, and stakeholder notifications.

The solution eliminates repetitive manual tasks, improves response times, and provides better visibility into request progress through centralized tracking and automated communications.

Key Features
📋 Request submission through Microsoft Forms
✅ Automated approval workflows using Power Automate
📁 Centralized request tracking in SharePoint Online
📧 Automatic email notifications for approvals and rejections
💬 Microsoft Teams notifications for real-time updates
🔄 Request status management and audit trail
📊 Optional Power BI dashboard for reporting and insights
